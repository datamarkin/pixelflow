---
title: Zones
description: Annotate zones on an image with superior visualization capabilities.
---

## Overview

This function draws polygon zones with customizable appearance, automatic counting, and labeling.

## Function Signature

```python
zones(
    image: np.ndarray,
    opacity: float = 0.3,
    border_thickness: int = None,
    show_counts: bool = True,
    show_names: bool = True,
    font_scale: float = None,
    font_thickness: int = None,
    text_color: tuple, optional = None,
    text_bg_color: tuple, optional = None,
    text_bg_opacity: float = 0.7,
    count_position: str = 'center',
    draw_filled: bool = True,
    draw_border: bool = True
) -> np.ndarray
```

## Parameters

<ParamField path="image" type="np.ndarray" required>
  Input image to annotate zone_manager: ZoneManager instance containing zones to draw
</ParamField>

<ParamField path="opacity" type="float" optional default="0.3">
  Fill opacity for zones (0.0-1.0). Default 0.3.
</ParamField>

<ParamField path="border_thickness" type="int" optional default="None">
  Thickness of zone borders. Default 2.
</ParamField>

<ParamField path="show_counts" type="bool" optional default="True">
  Display detection count in each zone. Default True.
</ParamField>

<ParamField path="show_names" type="bool" optional default="True">
  Display zone names. Default True.
</ParamField>

<ParamField path="font_scale" type="float" optional default="None">
  Scale of text labels. Default 0.7.
</ParamField>

<ParamField path="font_thickness" type="int" optional default="None">
  Thickness of text. Default 2.
</ParamField>

<ParamField path="text_color" type="tuple, optional" optional default="None">
  RGB color for text. If None, uses UI text color.
</ParamField>

<ParamField path="text_bg_color" type="tuple, optional" optional default="None">
  RGB color for text background. If None, uses UI background.
</ParamField>

<ParamField path="text_bg_opacity" type="float" optional default="0.7">
  Opacity of text background. Default 0.7.
</ParamField>

<ParamField path="count_position" type="str" optional default="'center'">
  Position for count display ('center', 'top', 'bottom').
</ParamField>

<ParamField path="draw_filled" type="bool" optional default="True">
  Whether to fill zones with color. Default True.
</ParamField>

<ParamField path="draw_border" type="bool" optional default="True">
  Whether to draw zone borders. Default True.
</ParamField>

## Returns

<ResponseField name="result" type="np.ndarray">
  Annotated image with zones visualized
</ResponseField>
