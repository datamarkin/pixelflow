This module defines the STrack class which represents a single tracked object and manages its state throughout the tracking process.

## Classes

- [`TrackState`](#trackstate) - Enumeration of possible track states.
- [`STrack`](#strack) - Single object track class for ByteTrack.

## TrackState

Enumeration of possible track states.

## STrack

Single object track class for ByteTrack.

Represents a single tracked object with its state, motion model, and tracking history.
