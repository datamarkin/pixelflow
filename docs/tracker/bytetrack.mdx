## Overview

ByteTrack tracker for multi-object tracking.

ByteTrack associates every detection box instead of only high-confidence ones, utilizing similarities with existing tracklets to recover true objects from low-confidence detections while filtering out background.

## Class Overview

The `ByteTracker` class provides structured data management for bytetracker operations.
