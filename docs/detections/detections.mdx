Provides unified data structures for representing detection results from various computer vision frameworks, including bounding boxes, masks, keypoints, and tracking information. Designed for efficient processing and seamless integration across different ML frameworks and visualization tools.

## Classes

- [`KeyPoint`](#keypoint) - Represents a single keypoint with coordinate and visibility information for pose estimation.
- [`Detection`](#detection) - Unified representation of a single object detection with comprehensive metadata and tracking.
- [`Detections`](#detections) - Container for multiple Detection objects with comprehensive filtering and processing capabilities.

## KeyPoint

Represents a single keypoint with coordinate and visibility information for pose estimation.

Stores spatial coordinates and visibility state for structured keypoint data representation in pose estimation and object keypoint detection tasks. Provides a standardized format for keypoint data across different ML frameworks and coordinate systems.

### Parameters

<ParamField path="x" type="int" required>
  X coordinate in pixels from image left edge.
</ParamField>

<ParamField path="y" type="int" required>
  Y coordinate in pixels from image top edge.
</ParamField>

<ParamField path="name" type="str" required>
  Descriptive name or label for the keypoint (e.g., "nose", "left_eye").
</ParamField>

<ParamField path="visibility" type="bool" required>
  Whether the keypoint is visible and detectable in the image.
</ParamField>

### Example

```python Example
import pixelflow as pf

# Create a keypoint for pose estimation
nose_point = pf.detections.KeyPoint(x=320, y=240, name="nose", visibility=True)
print(f"Nose at ({nose_point.x}, {nose_point.y})")

# Create keypoint with occlusion
hidden_point = pf.detections.KeyPoint(x=150, y=200, name="left_elbow", visibility=False)

# Use in detection workflow
keypoints = [nose_point, hidden_point]
detection = pf.detections.Detection(keypoints=keypoints, class_name="person")

```

## Detection

Unified representation of a single object detection with comprehensive metadata and tracking.

Stores complete detection information including bounding boxes, segmentation masks, keypoints, classification data, tracking information, and spatial analytics. Provides a standardized interface for detection data across different ML frameworks with automatic validation and type conversion for consistent data handling.

### Parameters

<ParamField path="inference_id" type="Optional[str]" optional>
  Unique identifier for the inference session or batch.
</ParamField>

<ParamField path="bbox" type="Optional[List[float]]" optional>
  Bounding box coordinates in XYXY format [x1, y1, x2, y2]. Automatically validated and normalized.
</ParamField>

<ParamField path="masks" type="Optional[List[Any]]" optional>
  Segmentation masks in various formats (binary arrays, polygons).
</ParamField>

<ParamField path="segments" type="Optional[List[Any]]" optional>
  Polygon segments for precise object boundaries.
</ParamField>

<ParamField path="keypoints" type="Optional[List[KeyPoint]]" optional>
  List of KeyPoint objects for pose/structure data.
</ParamField>

<ParamField path="class_id" type="Optional[Union[int, str]]" optional>
  Numeric or string class identifier from model.
</ParamField>

<ParamField path="class_name" type="Optional[str]" optional>
  Human-readable class name (e.g., "person", "vehicle").
</ParamField>

<ParamField path="labels" type="Optional[List[str]]" optional>
  Additional classification labels or attributes.
</ParamField>

<ParamField path="confidence" type="Optional[float]" optional>
  Detection confidence score [0.0-1.0], automatically rounded to 4 decimal places for consistency.
</ParamField>

<ParamField path="tracker_id" type="Optional[int]" optional>
  Unique tracking identifier for multi-frame object tracking.
</ParamField>

<ParamField path="data" type="Optional[Dict[str, Any]]" optional>
  Additional custom metadata and framework-specific data.
</ParamField>

<ParamField path="zones" type="Optional[List[str]]" optional>
  List of zone identifiers the detection intersects. Defaults to empty list if None.
</ParamField>

<ParamField path="zone_names" type="Optional[List[str]]" optional>
  Human-readable names for intersected zones. Defaults to empty list if None.
</ParamField>

<ParamField path="line_crossings" type="Optional[List[Dict]]" optional>
  Line crossing events for this detection. Defaults to empty list if None.
</ParamField>

<ParamField path="first_seen_time" type="Optional[float]" optional>
  Timestamp when detection first appeared (Unix time).
</ParamField>

<ParamField path="total_time" type="float" required>
  Total duration since first detection in seconds. Default is 0.0.
</ParamField>

## Detections

Container for multiple Detection objects with comprehensive filtering and processing capabilities.

Provides a unified interface for managing collections of detections with support for iteration, indexing, filtering, zone management, serialization, and bulk operations. Implements standard Python container protocols and includes dynamically attached filter methods for zero-overhead detection processing and analysis workflows.

### Example

```python Example
import pixelflow as pf
from ultralytics import YOLO
import cv2

# Create detections from ML framework
image = cv2.imread("image.jpg")
model = YOLO("yolo11n.pt")
outputs = model.predict(image)
detections = pf.detections.from_ultralytics(outputs)

# Manual creation and management
detections = pf.detections.Detections()
```
