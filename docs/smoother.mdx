## Overview

Smoother module for temporal detection smoothing.

This module provides buffer-based smoothing to reduce bbox jitter and confidence fluctuations for tracked objects using temporal context.

Uses past, current, and future frames for superior smoothing quality with temporal weighting and interpolation for missing detections.

## Function Signature

```python
smooth(
) -> Any
```

## Returns

<ResponseField name="result" type="Any">
  Smoothed Detections object for the current (middle) frame, or raw results if buffer not ready
</ResponseField>
