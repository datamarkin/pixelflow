# Slicer

Sliced inference for detecting small objects in large images.

This module provides high-accuracy object detection on large images by: 1. Slicing images into overlapping tiles 2. Running inference on each slice 3. Merging predictions with intelligent NMS/NMM Designed for simplicity and performance following PixelFlow principles.

## SlicedInference

Performs sliced inference on large images for improved small object detection.

The main challenge in sliced inference is accurately merging predictions from overlapping slices. This implementation handles edge cases like: - Objects on slice boundaries - Nested objects (small inside large) - Partial detections at slice edges
