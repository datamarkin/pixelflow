## SlicedInference

Performs sliced inference on large images for improved small object detection.

The main challenge in sliced inference is accurately merging predictions from overlapping slices. This implementation handles edge cases like: - Objects on slice boundaries - Nested objects (small inside large) - Partial detections at slice edges
