## Overview

Annotate multiple line zones on an image.

This is a convenience function that draws all lines managed by a Lines object.

## Function Signature

```python
line_zones(
    image: np.ndarray
) -> np.ndarray
```

## Parameters

<ParamField path="image" type="np.ndarray" required >
  Input image to annotate lines_manager: Lines manager object containing multiple lines
</ParamField>

## Returns

<ResponseField name="result" type="np.ndarray">
  Annotated image with all lines drawn
</ResponseField>
