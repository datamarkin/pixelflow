## Overview

Overlays binary masks on a video frame with improved performance.

## Function Signature

```python
mask(
    frame: np.ndarray,
    opacity: float,
    colors: list, optional
) -> np.ndarray
```

## Parameters

<ParamField path="frame" type="np.ndarray" required >
  The video frame (BGR format). results: List of results containing masks (e.g., from a model's output).
</ParamField>

<ParamField path="opacity" type="float" required >
  Opacity level for blending masks with the frame (0.0 to 1.0).
</ParamField>

<ParamField path="colors" type="list, optional" required >
  List of BGR color tuples to override default colors. Colors are mapped to unique class_ids in order of appearance. If None, uses default ColorManager colors.
</ParamField>

## Returns

<ResponseField name="result" type="np.ndarray">
  The frame with masks overlaid.
</ResponseField>
