## Overview

Applies pixelation effect to detected regions in the image with padding.

The pixelation effect is achieved by downscaling and then upscaling the region of interest, which reduces detail and creates a blocky appearance. This implementation uses OpenCV's optimized resize functions which leverage SIMD instructions for best performance.

## Function Signature

```python
pixelate(
    image: np.ndarray,
    pixel_size: int,
    padding_percent: float
) -> np.ndarray
```

## Parameters

<ParamField path="image" type="np.ndarray" required >
  Input image to apply pixelation on results: List of detection results containing bounding boxes
</ParamField>

<ParamField path="pixel_size" type="int" required >
  Size of the pixelation blocks. Larger values create more pixelated/blocky appearance. Default is 10 (softer). Must be > 0.
</ParamField>

<ParamField path="padding_percent" type="float" required >
  Padding to add around detection as percentage of box size. Default is 0.05 (5% from each side).
</ParamField>

## Returns

<ResponseField name="result" type="np.ndarray">
  Image with pixelated regions where objects were detected
</ResponseField>

## Performance Notes
