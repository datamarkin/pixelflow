## Overview

Enhanced label annotator with advanced features and simpler API.

This function provides a superior labeling system with automatic overlap prevention, template-based formatting, and flexible positioning - all while being simpler to use than traditional annotators.

## Function Signature

```python
label(
    image: np.ndarray,
    labels: list, optional,
    position: str,
    template: str, optional,
    style: dict, optional,
    auto_arrange: bool,
    padding: int,
    margin: int,
    max_width: int, optional,
    opacity: float,
    rounded: int,
    shadow: bool,
    gradient: bool
) -> np.ndarray
```

## Parameters

<ParamField path="image" type="np.ndarray" required >
  Input image to annotate results: List of detection results containing bounding boxes
</ParamField>

<ParamField path="labels" type="list, optional" required >
  Custom labels for each detection. If None, auto-generates from class_name and confidence
</ParamField>

<ParamField path="position" type="str" required >
  Label position relative to bbox. Options: 'top_left', 'top_center', 'top_right', 'center_left', 'center', 'center_right', 'bottom_left', 'bottom_center', 'bottom_right'
</ParamField>

<ParamField path="template" type="str, optional" required >
  Format template for auto-generating labels. E.g., "{class_name}: {confidence:.1%}" Available fields: class_name, confidence, class_id, tracker_id
</ParamField>

<ParamField path="style" type="dict, optional" required >
  Advanced styling options: {'font_scale': 0.5, 'font_thickness': 1, 'font_color': (255,255,255), 'bg_color': 'auto', 'border_color': None, 'border_width': 0}
</ParamField>

<ParamField path="auto_arrange" type="bool" required >
  Automatically prevent label overlaps. Default True.
</ParamField>

<ParamField path="padding" type="int" required >
  Padding inside label background. Default 5.
</ParamField>

<ParamField path="margin" type="int" required >
  Margin between label and bbox edge. Default 2.
</ParamField>

<ParamField path="max_width" type="int, optional" required >
  Maximum label width in pixels before text wrapping.
</ParamField>

<ParamField path="opacity" type="float" required >
  Background opacity (0.0-1.0). Default 0.7.
</ParamField>

<ParamField path="rounded" type="int" required >
  Corner radius for rounded rectangles. 0 = sharp corners.
</ParamField>

<ParamField path="shadow" type="bool" required >
  Add drop shadow effect. Default False.
</ParamField>

<ParamField path="gradient" type="bool" required >
  Use gradient background. Default False.
</ParamField>

## Returns

<ResponseField name="result" type="np.ndarray">
  Annotated image with enhanced labels
</ResponseField>
